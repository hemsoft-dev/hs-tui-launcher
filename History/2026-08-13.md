# 2026-08-13

## Added direct Moonshot AI launcher

Added a top-level Kimi K3 entry that uses Moonshot API credits through an
isolated OpenCode provider configuration and reads the credential from the
system-level `KIMI_K3_API_KEY` environment variable.

## Pinned OpenRouter DeepSeek V4 Flash to 0731

Changed the OpenRouter choice from the April unversioned model to the explicit
July 31 revision and refreshed its displayed input/output pricing to
`$0.08/$0.18` per million tokens.

## Refreshed OpenRouter pricing guidance

Updated GLM 5.2 to the current `$0.50/$3.15` OpenRouter catalog rate and
clarified that multi-provider routing can result in different actual charges.

## Added Seedream 5.0 Pro image generation

Added `bytedance-seed/seedream-5-0-pro` to the OpenRouter submenu as a dedicated
Images API action rather than an unsupported OpenCode chat model. The launcher
collects the prompt, 1K/2K resolution, and aspect ratio, confirms the estimated
per-image charge, and saves the returned image under the user's Pictures folder.
