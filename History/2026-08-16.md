# 2026-08-16

## Added local Ollama launcher

Added Ollama as a top-level model submenu driven by OpenCode. The first choice
launches the local `qwen3.8:27b` model through an inline provider definition,
without changing the user's global OpenCode configuration.

## Added Seedream prompt files

Seedream image generation now accepts a pasted text-file path at the image
description prompt. The launcher reads the file as UTF-8 and uses its contents
as the prompt while preserving direct text entry.

## 20:36 - Added AMD Ollama to GitHub Copilot

Added a Home-only GitHub Copilot menu choice and scoped PowerShell wrapper for
`qwen3.8:27b` on `amd`, with offline BYOK mode and the full 262,144-token context
window.

## 21:23 - Added AMD models to OpenCode

Added distinct OpenCode choices for Qwen 3.8 27B on `home` and `amd`, plus the
downloaded Qwen3-Coder 30B A3B and GPT-OSS 120B Lemonade models on `amd`.
Lemonade stays loopback-only and is reached through a temporary SSH tunnel that
closes with the OpenCode session. Backend selection releases the other server's
loaded model to prevent competing large context caches from exhausting AMD's
unified GPU-memory pool, but refuses to interrupt an active client.
